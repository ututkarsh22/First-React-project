# First React Project – Learning React Through Practice

This is a **frontend-only** project created to learn the fundamentals of **React.js**. It simulates a basic Travel booking UI and helped me understand how components, props, and state work together in a React app.
I named this website GuiderPro...

---

## 📚 What I Learned

-  How to create and use **React components**
-  How **JSX** works under the hood
-  How to pass and manage **props**
-  Basic **stateful UI** using functional components
-  Styling in React using **CSS**
-  Folder structuring and **project setup** with Vite

---

## 🧱 Tech Stack

- ⚛️ **React.js**
- 💨 **Vite** (React + Vite Starter Template)
- 🎨 **Tailwind CSS**

## 🚀 Getting Started

To run this project locally:

```bash
# Clone the repository
git clone https://github.com/yourusername/First-React-project.git

# Navigate to project directory
cd First-React-project

# Install dependencies
npm install

# Start development server
npm run dev
